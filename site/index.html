Vinayak Creation

GST invoicing and monthly reports for the CA

What it does

A web app for making GST tax invoices laid out like the paper pad. It works in any browser on a phone or a laptop.

  • Worker: makes invoices, views, prints or downloads them as PDF, and adds customers.
  • Owner: everything above, plus cancelling invoices, the monthly Excel/PDF report, settings and user accounts.
  • Past ledger bills can be imported from a spreadsheet template.
  • Daily automatic database backups.
See a sample invoice (PDF) Source code on GitHub

Run it yourself

Python 3.10 or newer. This page is only a showcase: the app keeps its data in a SQLite file and needs a Python host, so it does not run on GitHub Pages.

git clone https://github.com/AtulSwain/Invoice-system.git
cd Invoice-system
python -m venv .venv
pip install -r requirements.txt
python seed.py
python run.py

Then open http://localhost:8000. Full steps, including putting it online, are in the README.

Built with Python, Flask, SQLite, openpyxl and reportlab.
